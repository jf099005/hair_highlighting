挑染還原階段報告

2026-11-08 · 單張照片 → DiffLocks 3D 髮絲 + 每根髮絲的挑染 / 未挑染分區。本階段以分區為主，顏色暫不處理。報告模型 {{RUN}}。

結論

  • 把每根髮絲投影回影像取特徵是關鍵：同樣資料下，純影像 → 頭皮 mask 的可見髮絲 IoU 只有 0.19，髮絲投影模型 0.70（92 個樣本）→ 0.83（全部資料）。
  • dense 從 0.50 進步到 0.67（可見髮絲 IoU；precision 0.67 → 0.86）：顏色 loss 降低、256² 細特徵、依風格平衡抽樣 + 較長訓練各自有效。 可見條紋約 84–89% 找得到，錯誤主要在邊界與寬度；被頭髮蓋住的細條紋仍幾乎推不出來（全部髮絲 IoU 0.27）。
  • DiffLocks 重建的髮型是目前的天花板：就算每根可見髮絲都標對，money piece 的正面標籤圖 IoU 也只有 0.31，因為重建的髮絲不在影像上挑染的位置。 要再進步得改髮絲幾何，而不是只改標籤。
  • 後處理：隨機 mask 用 FM 很好（IoU 不變、grid score 降 2–3 倍）；dense / money piece 用 FM 會把挑染刪光。 投影到生成器的 Bezier mask 家族再跑 rlift_bf，能得到乾淨、符合生成風格的條紋（grid score 下降），但對 GT 標籤圖的 IoU 通常下降；以下面的渲染判斷。
  • 真實照片：分區位置大致對（白色區塊、框臉帶、金色束），但受 DiffLocks 幾何與五官對齊誤差影響，邊界粗糙。

方法

輸入照片 → DiffLocks 臉部裁切；真實照片以五官 landmark 對齊
髮型DiffLocks 重建（訓練用 GT 髮型），每根取 32 點投影回影像 + z-buffer 深度差
模型DINOv2 + CNN（128² 與 256²）在投影點取樣 → 可見度加權池化 → 4 層髮絲 transformer
輸出每根髮絲挑染機率（+ 頭皮 mask、2D 像素分類）
後處理隨機：FM；dense / money piece：投影到 Bezier mask 家族 + rlift_bf

Loss：髮絲 BCE + Dice（被遮住的髮絲權重 0.3）、0.5 × 4 類像素 CE、0.1 × 顏色 L1。增強：隨機背景與膚色、亮度 / 色彩擾動、裁切平移縮放、左右翻轉。 資料：dense 118 / money piece 316 / 隨機 mask 151，依髮型切 train 512 / test 71，全部以隨機 RGB（ΔE ≥ 45）+ optical 幾何重新渲染。

數字

test 樣本的中位數。可見 IoU：至少一點看得到的髮絲上的挑染 IoU；全部 IoU：含被遮住的髮絲；條紋找回率：可見的 GT 條紋 / 片中，被判為挑染（≥ 50% 髮絲）的比例。 最後一列是報告用的模型。

限制與下一步

  • 依影像移動髮絲（把判為挑染的髮絲帶到影像上挑染的位置）以突破 DiffLocks 幾何天花板；rlift_bf 的抬升可以當起點。
  • dense 被遮住的條紋：以生成器的條紋結構（對稱、等距、從分線出發）做結構化預測，而不是逐根分類。
  • Bezier 投影目前由人指定風格（dense / money piece），之後可讓模型預測風格。
  • 顏色：照片外觀 → 渲染參數的校正（目前的 render curve 轉換誤差大）。
  • 所有比較都是單一 seed、test 71 個樣本；後處理比較只有 9 個代表 case。
