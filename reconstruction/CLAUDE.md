# CLAUDE.md

本資料夾研究「從一張挑染頭髮照片同時還原 3D 髮型與髮色 / 挑染圖樣」：在 DiffLocks（`../../NCKU_3D_hair_reconstruction`）
還原髮型的基礎上，加上還原 base 髮色、挑染髮色，以及哪些髮絲是挑染。目前先處理非漸層的挑染。

訓練資料來自 `../generate_from_3D_models` 產生的挑染樣本（真實 3D 髮型 + 已知的每根髮絲標籤與顏色 + 渲染影像）。
預測出的挑染之後可以接上與資料產生相同的 mask / 髮流修正，讓結果在 3D 中看起來乾淨。

判斷好壞以渲染與真實照片上的外觀為準，不只看平均分數。架構、輸入、輸出格式與 loss 都還在探索，會大幅改動；
目前的作法與用法看 README，結果看 SUMMARY.md，紀錄看 LOG.md，可用版本看 checkpoints.md。
